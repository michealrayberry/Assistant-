Requirements

A requirement defines what a valid session looks like: the instructions, the minimum duration, and the rules that invalidate a session. The Accountability Partner can author one here, export it, and send the file to the participant to import — its fingerprint appears in every packet so the partner can confirm the right requirement was followed.

Hosted mode

Checking for a server…

To host your own: download server.js from the repository and run node server.js (Node 18+, no install needed) — then open http://localhost:8787, or deploy it to any Node host. Hosted mode adds server-witnessed seal timestamps (the seal is registered the instant a session completes, replacing the manual text-the-code step) and automatic packet delivery to the partner's inbox, with an optional webhook notification.

Participant — connect to your Accountability Partner

Connecting imports the partner's requirement and turns on automatic delivery: every completed session registers its seal with the server (trusted timestamp) and uploads its packet to the partner's inbox on its own.
